# BFBotForge Cyp

Professional bot hosting and deployment frontend, redesigned with a clean SaaS interface, subtle developer/code background, responsive UI and Light/Dark Mode.

## Included
- Public landing page
- Login and registration UI
- Dashboard with sidebar
- Bot marketplace and empty-state handling
- Deployment flow
- Wallet/deposit UI (KES 50–3,000)
- M-Pesa/Paystack-ready payment architecture
- Notifications/rewards/recovery navigation foundation
- Responsive mobile design
- Light/Dark Mode
- Repaired missing JavaScript files referenced by the original HTML

## Important
The static ZIP cannot provide production authentication, payment verification or actual bot hosting by itself. Before accepting real users/payments, connect a secure backend for authentication/session management, Google/GitHub OAuth, M-Pesa Daraja or another verified M-Pesa provider, Paystack webhooks, wallet ledgering, bot deployment infrastructure and admin controls.

Never expose payment secrets or deployment credentials in frontend JavaScript. Never credit a wallet based only on a browser success message.
